In this project I designed a 32-tap fixed-point FIR low-pass filter in Verilog for FPGA-based digital signal processing using Q1.15 arithmetic. 
I focused on FM radio signals that were captured using an RTL-SDR receiver and analyzed them in Python using FFT-based spectral analysis to validate the filter's frequency 
response and design specifications. The FIR architecture was built using shift registers and multiply-accumulate (MAC) logic which was verified through simulation.
